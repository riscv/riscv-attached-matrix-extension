[#ame:doc:inst:asettyp]
=== `asettyp`

Synopsis::
Set accumulator datatype

Mnemonic::
`asettyp ad, rs1`

Encoding::
+
[wavedrom, ,svg,subs='attributes',width="100%"]
....
{"reg":[{"bits":7,"name": 0x2b,"type":2},{"bits":5,"name": "ad","type":4},{"bits":3,"name": {ame-enc-funct3},"type":2},{"bits":5,"name": "rs1","type":4},{"bits":5,"name": 0x1,"type":2},{"bits":7,"name": {ame-enc-r2-bank0-funct7},"type":2}]}
....

Description::
Sets the datatype of an `Acc` register and clears every physical storage bit of
the accumulator to zero.  This is a raw-bit clear, not conversion to the new
datatype's semantic zero.  The new 32-bit descriptor is `X[rs1][31:0]`; any
upper X-register bits are ignored.

Operation::
+
[source]
----
Ad[ad] = X[rs1][31:0]; raw_bits(Acc[ad]) = 0
----

Synopsis::

Mnemonic::
`mmove.m.x md, rs1, rs2`

+
[wavedrom, ,svg,subs='attributes',width="100%"]

`pack_factor = 1` and therefore square index zero.

unsupported under
<<norm:ame_op_supported_contract,the unsupported-datatype-tuple contract>>.

j = pos % N
